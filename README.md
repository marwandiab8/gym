# gym

## Frontend build

The pages use a prebuilt Tailwind stylesheet (`public/tailwind.css`) and a service worker (`public/sw.js`) so the installed app opens fast and works offline. Both are generated by `scripts/build-assets.mjs`, which `firebase deploy --only hosting` runs automatically (`hosting.predeploy`). Run `npm install` once in the project root first, and `npm run build:assets` after changing markup or Tailwind classes if you want to preview the result without deploying.
